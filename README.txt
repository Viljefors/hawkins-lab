HAWKINS LAB — тестовий перший етап

1. Створіть НОВИЙ репозиторій hawkins-lab у GitHub (не змінюйте system-failure).
2. Завантажте index.html і config.js з цього архіву в корінь нового репозиторію.
3. Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
4. Відкрийте https://viljefors.github.io/hawkins-lab/
5. На двох пристроях введіть однаковий код кімнати. Один вибирає оператора, інший гравчиню.

Стан зберігається в Firebase за адресою rooms/HAWKINS_<КОД>, відокремлено від старих кімнат.

Увага: ця тестова версія не має захищеного входу оператора. Використовуйте тільки для сімейного квесту; перед публікацією фінальної версії варто додати контроль доступу.
