HAWKINS LAB — ЕТАП 1, ТЕСТОВА ВЕРСІЯ 2

РОЗГОРТАННЯ
1. У GitHub-репозиторії viljefors/hawkins-lab відкрий корінь гілки main.
2. Замінити index.html на файл із цього архіву. config.js також додається, але якщо чинний config.js вже працює, можна залишити його без змін.
3. GitHub Pages має бути увімкнено: Deploy from a branch → main → /(root).
4. Відкрити https://viljefors.github.io/hawkins-lab/ на телефоні Ані й на телефоні/ПК оператора.
5. На обох пристроях ввести ОДНАКОВИЙ код сеансу (наприклад ANYA13).
6. На телефоні Ані натиснути «ЕКРАН АНІ», на пристрої ведучого — «ПУЛЬТ ОПЕРАТОРА».
7. Аня натискає «ЗАПИТАТИ ДОСТУП», оператор підтверджує. Для звуку Аня натискає «ЗВУК: ВИМК.».
8. Після вступу оператор відтворює фізичні натискання: RED BLUE BLUE YELLOW GREEN RED YELLOW BLUE.
9. Помилка обнуляє прогрес. Після 8/8 відтворюється тестова радіограма, відеосилует ученого, далі оператор відкриває повне повідомлення.

ВАЖЛИВО
- Відеосилует — анімована CSS-ілюстрація, а не справжній відеофайл.
- Аудіо — синтезовані сигнали, не музика/голос.
- На телефоні Ані екран розрахований на горизонтальну орієнтацію.
- Дані пишуться в Firebase за адресою rooms/HAWKINS_<КОД>, окремо від попереднього квесту.
- Сайт НЕ має захищеної авторизації оператора: будь-хто з посиланням та кодом кімнати може обрати роль оператора. Для домашнього тесту не розповсюджуйте код.
- Потрібна увімкнена Anonymous Authentication і доступні правила Firebase Realtime Database.
- Звук потребує натискання користувача через обмеження браузерів.
- GitHub Pages не змінюється автоматично: файли потрібно завантажити вручну.
